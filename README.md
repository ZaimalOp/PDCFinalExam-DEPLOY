# 🌐 Distributed Systems Image Classification

> A modern web application demonstrating **REST**, **tRPC**, and **gRPC** communication concepts through an AI-powered image classification interface. Built as a Distributed Systems final project with a responsive dashboard, real-time logs, and performance monitoring.

---

## ✨ Features

- 📤 Drag & Drop image upload
- 🤖 AI image classification
- 🌐 REST API integration
- ⚡ tRPC protocol simulation
- 🔗 gRPC protocol demonstration
- 📊 Real-time latency measurement
- 🖥 Interactive terminal logs
- 📈 Live request status monitoring
- 📱 Responsive Bootstrap UI
- ☁️ Vercel-ready deployment

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/distributed-systems-exam.git
```

Navigate to the project

```bash
cd distributed-systems-exam
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

or deploy directly to **Vercel**.

## 🌐 Supported Protocols

| Protocol | Purpose |
|----------|----------|
| REST | Standard HTTP API |
| tRPC | End-to-end type-safe communication |
| gRPC | High-performance RPC architecture |

> **Note:** In the Vercel deployment, requests are routed through the REST endpoint since native tRPC/gRPC servers require dedicated runtime environments.
